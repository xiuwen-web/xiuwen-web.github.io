# HyperFrames skills (vendored)

Claude Code skills for HTML-based video creation and editing, copied from
[heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) `skills/`
at commit `3de4763d53de194b4ddc4d5d8f724fe0e3b3ca74` (2026-10-13).
Licensed under Apache 2.0 — see `HYPERFRAMES-LICENSE`.

Start with `/hyperframes`. Requires Node.js 22+ and FFmpeg; run
`npx hyperframes doctor` to check. Voiceover/TTS features need a HeyGen or
Gemini API key.

To update, replace these folders with the latest `skills/` from upstream.
These files are excluded from the site's ESLint and TypeScript checks and are
not part of the built site.
